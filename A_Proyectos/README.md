# A · Proyectos

Presentación del proyecto educativo de UNIverse One.

## Reto
Build a Junior Astronaut Mission Trainer.

## Objetivo
Desarrollar una simulación educativa de un puesto lunar que permita
explorar cómo la gestión de recursos afecta la supervivencia de la
tripulación y el éxito de la misión.
