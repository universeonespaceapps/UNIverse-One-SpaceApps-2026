explaining who worked on it and what the images show.

## NASA Data and References
For each source, document:
- Resource title.

- How it was used in the project.

## Third-Party Resources and Credits
For each external asset, document:
- Asset name and creator.
- Original source URL.
- License or permission information.
- Where it was used in the game.

This includes music, sound effects, images, textures, HDRIs,
3D models, fonts, and external code when applicable.
