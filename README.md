# UNIverse One
## NASA Space Apps Challenge 2026

**Challenge:** Build a Junior Astronaut Mission Trainer  
**Team:** UNIverse One  
**Local event:** Guatemala, Guatemala  
**Technology:** Unity 6000.4.4f1 and C#

## Project overview

UNIverse One is developing an educational game that introduces
students to the challenges of operating a lunar outpost.

The project aims to help players understand how decisions about
power, life support, radiation shielding, and food production
affect crew survival and mission success.

## Educational objective

Turn space engineering concepts into an interactive learning
experience where players explore resource management,
decision-making, and the consequences of competing mission needs.

## Development status

The project is currently under development and integration.

The main menu includes navigation to the game, options,
controls, and credits. Final gameplay integration, documentation,
and delivery testing are in progress.

## Project materials

The following materials will be added as they are completed:

## NASA data and other resources
