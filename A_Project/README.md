## Project Overview
UNIverse One is developing an educational lunar outpost simulation.

The project aims to help students explore how decisions about energy,
life support, radiation shielding, and food production affect crew
survival and mission success.

## Educational Objective
Introduce space engineering concepts through interactive exploration,
resource management, and decision-making.
